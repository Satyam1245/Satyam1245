## 🤖 AI & Machine Learning Projects

### 🧠 [JAX Reinforcement Learning Platform](https://github.com/Satyam1245/jax-rl-platform)

A modular reinforcement learning platform built using **JAX, Flax, Optax, and Gymnasium**, designed to implement and experiment with multiple reinforcement learning algorithms.

**Key Features:**
- Implements DQN, Proximal Policy Optimization (PPO), and one-step Actor-Critic.
- Shared training and evaluation engines.
- YAML-based configuration and experiment management.
- Checkpoint saving, restoration, and deterministic evaluation.
- Experiment history, performance metrics, and algorithm comparison.
- Interactive Streamlit dashboard with Plotly visualizations.
- Unit, integration, and smoke-test suites.

**Tech Stack:** Python, JAX, Flax, Optax, Gymnasium, NumPy, Pandas, Plotly, Streamlit, PyYAML, pytest.

### 🔍 [DeepTrace AI | DeepFake Detector](https://github.com/Satyam1245/deeptrace-ai-detector)

An AI-powered multimodal deepfake detection system combining deep learning, computer vision, and digital forensic analysis to investigate potentially manipulated images, videos, and audio.

**Key Features:**
- Image analysis using MTCNN and EfficientNet.
- GradCAM-based explainability and X-Ray visualization.
- FFT frequency-domain analysis and Error Level Analysis (ELA).
- Video frame extraction and temporal consistency analysis.
- Audio preprocessing and synthetic speech detection heuristics.
- Interactive forensic dashboard with confidence and threat scoring.

**Tech Stack:** Python, PyTorch, EfficientNet, FastAPI, OpenCV, MTCNN, NumPy, Pandas, SciPy, Matplotlib.

### 🎯 [Face Recognition Attendance System](https://github.com/Satyam1245/Face-Recognition-Attendance-System)

A Python-based automated attendance management system using OpenCV and Local Binary Patterns Histograms (LBPH) face recognition.

**Key Features:**

- Haar Cascade face detection.
- LBPH-based face recognition.
- Automated attendance recording with duplicate prevention.
- Timestamp-based attendance records.
- Approximate location tagging using IP-based geolocation.

**Tech Stack:** Python, OpenCV, LBPH, Haar Cascade, NumPy, Geocoder.
